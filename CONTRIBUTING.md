# Guia de Contribuição

Ficamos muito felizes que você queira contribuir com o nosso projeto! Siga os passos abaixo para garantir que tudo ocorra de forma tranquila.

## Passo a Passo

1. Faça um **Fork** do projeto.
2. Crie a sua branch para a nova feature ou correção: `git checkout -b minha-feature`.
3. Faça os commits das suas alterações de forma descritiva: `git commit -m 'feat: adicionando nova funcionalidade'`.
4. Faça o push para a branch: `git push origin minha-feature`.
5. Abra um **Pull Request** detalhando o que foi feito.

## Padrão de Commits
Utilizamos o padrão de Commits Semânticos:
* `feat:` Uma nova funcionalidade
* `fix:` Uma correção de bug
* `docs:` Alterações na documentação
* `refactor:` Refatoração de código de produção (sem alterar comportamento)
* `test:` Adição ou modificação de testes
* `chore:` Atualizações de build, pacotes ou configurações
